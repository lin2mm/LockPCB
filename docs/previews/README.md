# Engineering overview preview

`engineering-overview.png` is a readable discussion graphic for the current PRE-CAD architecture and functional zones. It is illustrative and not to scale; the KiCad `.kicad_pcb` and `.kicad_sch` files remain the editable source of truth. Do not use this image for dimensioning, footprint placement, routing, fit verification, or fabrication. For precise layer visibility and CAD exports, use the KiCad project or the reports/renderings attached to the GitHub Actions run.
